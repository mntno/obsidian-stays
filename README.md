# Stays

Book guests into rooms for specific dates.

## Dependencies

This plugin requires:

- **[Datacore](https://community.obsidian.md/plugins/datacore)** – Query and filter booking data
- **[Full Calendar](https://community.obsidian.md/plugins/obsidian-full-calendar)** – Visual calendar view of reservations

Install these first before enabling this plugin.

## Usage

All actions are accessible via the Command Palette (`Ctrl/Cmd + Shift + P`).

### Core Commands

| Command | Description |
| --- | --- |
| `Add Person` | Create a new person |
| `Add Booking` | Assign a person to a room for a date range |
